# PatiDost — PLAN.md

1. **Altyapı & Token Kurulumu:** Vite + React 19 + TypeScript + Tailwind CSS v4 + PWA manifest + Google Fonts (`Outfit`, `Plus Jakarta Sans`).
2. **Durum & Katalog Katmanı:** `types.ts`, Türkçe görev paketleri, 12 kozmetik & oda teması, 4 büyüme evresi ve `localStorage` kalıcılığı.
3. **İzole Hero / Canlı Dost Sahnesi (`PetStage.tsx`):** Animasyonlu SVG **Mırnav** (tekir kedi) & **Pıtır** (kuş), takılabilir aksesuar katmanları, oda arka planları ve etkileşimli okşama.
4. **Mikro Görevler & Pomodoro Odaklanma (`MicroTasksPanel.tsx`, `FocusPomodoro.tsx`):** Paket seçimi, özel görev ekleme, dinlenme modu, gerçek geri sayım ve Web Audio çan sesi.
5. **Atölye & Ruh Hali Günlüğü (`WardrobeModal.tsx`, `MoodJournal.tsx`):** Puanla aksesuar/oda açma, canlı giydirme, 10 sn ruh hali kaydı ve JSON yedekleme.
6. **Canlı Tarayıcı QA & SEO:** Build doğrulaması, dev sunucuda mobil (`375px`) ve masaüstü (`1280px`) görsel + konsol + erişilebilirlik denetimi.
